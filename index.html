Personal Project · Full SDLC

GKZipPDF — SDLC Journey

A live production app. Every phase owned solo. Proof that initiative lives beyond the job description.

Visit Live Product ↗
01

Problem Statement

Real operational friction — extracting PDFs from ZIP files from e-commerce platforms like Nykaa & Myntra. No clean tool existed.

02

Requirements Gathering

Interview & Workshop techniques. MoSCoW prioritisation: ZIP→PDF & Compress (Must), Merge PDF (Should), PDF↔Word (Could), Image to PDF (Phase 2).

03

Design

Simple functional layout. Python Flask tech stack. Prioritised usability over aesthetics.

04

Development

Vibe-coded using LLMs — the spec I wrote became the blueprint for every component.

05

Testing

Unit testing · System testing with 100 ZIP files simultaneously · UAT with real users.

06

Deployment

GitHub → Vercel → Namecheap domain → DNS configuration. Live at gkzipdf.com.

07

Stakeholder Management

Mid-project Image-to-PDF request. Assessed impact, proposed phased approach — core now, feature in Phase 2.
